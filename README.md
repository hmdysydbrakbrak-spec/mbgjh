# بوت المكتبة الإسلامية — Telegram

بوت عربي بأقسام القرآن الكريم، صوتيات الشيوخ والعلماء، البودكاست، الأناشيد، والمكتبة الإسلامية. يدعم البحث وإضافة روابط من حساب المدير.

## النشر السحابي على Render

1. افتح لوحة Render وأنشئ Blueprint من هذا المستودع، أو أنشئ Background Worker واربطه بالمستودع.
2. راجع الخدمة قبل إنشائها. إعداد العامل يستخدم خطة مدفوعة لأن Render لا يوفّر Background Workers مجانية بحسب وثائقه الحالية.
3. أضف متغير البيئة BOT_TOKEN من @BotFather داخل إعدادات الخدمة. لا تضع التوكن في ملفات GitHub ولا ترسله لأي شخص.
4. اضبط ADMIN_ID إلى رقم حساب المدير. يمكن تشغيل البوت مؤقتًا ثم إرسال /id لمعرفة الرقم، وبعدها تحديث المتغير وإعادة النشر.
5. أمر التشغيل هو python bot.py. يجب أن تبقى خدمة واحدة فقط لأن Telegram long polling لا ينبغي تشغيله بنسختين بالتوكن نفسه.

## الأوامر

- /start أو /menu — القائمة الرئيسية
- /search كلمة — البحث في العناوين
- /id — معرفة رقم حساب تيليجرام
- /add quran|عنوان المحتوى|https://example.com — إضافة رابط (للمدير فقط)

الأقسام: quran, sheikhs, podcasts, nasheeds, library.

## التخزين والأمان

إعداد Render يركّب قرصًا دائمًا في /var/data حتى لا تضيع الروابط المضافة عند إعادة تشغيل الخدمة. لا تضف إلا روابط تملك حق مشاركتها أو روابط رسمية/مصرحًا بها. لو انكشف توكن البوت، ألغِه وأنشئ واحدًا جديدًا من BotFather.

إنشاء ملفات المشروع لا يعني أن البوت أصبح يعمل بالفعل. يلزم ربط حساب استضافة وإضافة BOT_TOKEN من داخل حسابك، ولا أستطيع إدخال أسرارك نيابة عنك.
